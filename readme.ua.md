**InfoNureBot** — це багатофункціональний Telegram-бот для студентів Харківського національного університету радіоелектроніки (ХНУРЕ). Бот забезпечує зручний доступ до розкладу занять (інтеграція з CIST) та системи дистанційного навчання ХНУРЕ ДН (Moodle API), а також надає інструменти для адміністрування студентських чатів.

## Основний функціонал

### Для студентів:
* **Розклад занять:** Перегляд розкладу на сьогодні, завтра, поточний/наступний тиждень або за довільним діапазоном дат (інтеграція з `cist.nure.ua`).
* **Інтеграція з Moodle (ХНУРЕ ДН):**
  * Авторизація за допомогою логіна та пароля (паролі шифруються за допомогою AES).
  * Перегляд актуальних оцінок з дисциплін.
  * Відстеження найближчих дедлайнів (до 30 днів).
* **Персоналізація:** Можливість закріпити за собою особисту академічну групу.
* **Зворотний зв'язок:** Система `/report` для зв'язку з адміністраторами бота.

### Для групових чатів:
* **Академічна група чату:** Адміністратор чату може встановити групу за замовчуванням для всього чату (`/set_chat_group`).
* **Довідкова інформація:** Збереження та виведення важливої інформації, посилань або старостинських нотаток (`/ref_info` та `/ref_info_edit`).

### Для адміністраторів бота:
* **Масова розсилка:** Асинхронна розсилка повідомлень всім користувачам та групам (`/adt`) з урахуванням лімітів Telegram API.
* **Модерація:** Блокування та розблокування порушників (`/ban`, `/unban`).
* **Відповіді на репорти:** Пряма відповідь користувачу через бота (`/answer`).

## Технологічний стек

* **Мова:** Java 21
* **Фреймворк:** Spring Boot 3.4.5
* **База даних:** PostgreSQL 16+
* **ORM:** Spring Data JPA / Hibernate
* **Telegram API:** TelegramBots (v6.9.7.1)
* **Парсинг та HTTP:** вбудований `java.net.http.HttpClient`, `Gson` (для обробки JSON), `Jsoup`
* **Інше:** Lombok

## Архітектура проєкту

Проєкт побудований за класичною багатошаровою (N-Tier) архітектурою з використанням сучасних патернів проєктування:

1. **Патерн Command:** Всі команди бота (наприклад, `/start`, `/timetable`) імплементують єдиний інтерфейс `BotCommand`, що забезпечує низьку зв'язність коду та легке масштабування. 
2. **State Machine (Скінченний автомат):** Діалоги з ботом реалізовані через збереження поточного стану користувача (`UserState`). Це дозволяє боту розуміти контекст повідомлень (наприклад, очікування вводу пароля або дати).
3. **Кешування:** Розклад з CIST кешується в базі даних (таблиця `cached_schedule`) для відмовостійкості. Кеш автоматично оновлюється у фоновому режимі щодня о 03:00 ночі.
4. **Безпека:** Паролі від системи Moodle не зберігаються у відкритому вигляді, а шифруються симетричним алгоритмом за допомогою JPA `AttributeConverter`.

## Структура Бази Даних (Схема `tg_bot`)

* `user_data` — інформація про користувачів, їхні налаштування та зашифровані доступи до Moodle.
* `group_data` — інформація про підключені групові чати Telegram (назва, прив'язана група, довідкова інформація).
* `cached_schedule` — закешовані JSON-дані розкладу з системи CIST.
* `banned_user` — чорний список користувачів та чатів.

## Локальний запуск (Setup & Installation)

1. **Клонуйте репозиторій:**
   bash
   git clone [https://github.com/your-username/infonure_bot.git](https://github.com/your-username/infonure_bot.git)
   cd infonure_bot

2. **Налаштуйте базу даних:**
   Створіть базу даних PostgreSQL (наприклад, `postgres`) та схему `tg_bot`.

3. **Створіть файл конфігурації:**
   У файлі `src/main/resources/application.properties` вкажіть свої дані:
   properties
   bot.name=YourBotName
   bot.token=YOUR_TELEGRAM_BOT_TOKEN
   bot.admin.ids=123456789 # ID адміністраторів через кому
   
   spring.datasource.url=jdbc:postgresql://localhost:5432/postgres
   spring.datasource.username=ваші_дані
   spring.datasource.password=ваші_дані

4. **Збірка та запуск (Maven):**
   bash
   ./mvnw clean install
   ./mvnw spring-boot:run
